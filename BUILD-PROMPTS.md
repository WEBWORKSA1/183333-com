# 183333.com — Phase-wise Build Prompts

**Concept:** *183333 · Residency Day Lab* — free multi-country day tracker, 183-day-rule calculators, country residency database, nomad-visa directory and expert-matching lead generation for digital nomads, expats, NRIs, snowbirds and global employers.
**Stack:** static HTML/CSS/vanilla JS · GitHub Pages (free) · Google AdSense `ca-pub-6620975821265271` · FormSubmit (AJAX) for forms with the inbox address obfuscated in JS (never written in HTML).

Use these prompts in order with any capable AI coding assistant. Each phase is self-contained and testable.

---

## Phase 1 — Foundation & design system
> Build a static website for the domain 183333.com titled "183333 — Residency Day Lab". Use only HTML, CSS and vanilla JS so it runs on GitHub Pages free hosting. Create `assets/css/style.css` with CSS custom properties for a dark navy theme (bg #0b1020, card #141c36, amber accent #ffb547, teal #2ee6c5) plus a `[data-theme="light"]` override; fonts Inter, Space Grotesk and JetBrains Mono from Google Fonts. Include responsive grid utilities (g2/g3/g4 collapsing at 980px and 640px), cards, buttons, form styles, tables with horizontal scroll, details/summary FAQ styling, cookie banner, reveal-on-scroll animation (respecting prefers-reduced-motion) and print styles that hide navigation and ads. Mobile first: no horizontal scroll at 360px.

## Phase 2 — Global layout on every page
> Create a shared header and footer used on every page. At the very top of every page add a full-width ribbon: "contact, if you are interested in this website/domain name/Sponsorship/Advertisement/Partnership" linking to https://web.works/contact (new tab). Sticky header with logo (SVG stamp containing "183"), nav links (Day Tracker, Calculators, Country Rules, Nomad Visas, Guides, Videos, Support), a highlighted "Get Matched" CTA, a theme toggle, and a burger menu under 1020px. Footer with 4 link columns (Tools, Learn, Community, Company + legal pages), an "Email us" link that opens the mail client via JS only, and a trademark line stating no rights are claimed in the number 183333. Add a cookie/consent notice stored in localStorage. In every `<head>` place the AdSense script `<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6620975821265271" crossorigin="anonymous"></script>`, the `google-adsense-account` meta tag, canonical URL, Open Graph tags and WebSite JSON-LD.

## Phase 3 — Hidden-email form engine
> Write `assets/js/main.js`. Store the destination inbox only as an XOR-obfuscated, reversed character-code array and decode it at runtime. Any `<form class="js-form">` posts JSON via fetch to `https://formsubmit.co/ajax/<decoded inbox>` with `_subject` from `data-subject`, `_template: table`, `_captcha: false`, the page path, and a hidden honeypot `_honey`. Show success/error messages inline. Support multi-step forms (`.multistep` with `.step` panels, progress bar, per-step validation). Any element with `data-mail` opens `mailto:` built at runtime. Confirm with a grep that the address never appears in any HTML/JS source as plain text.

## Phase 4 — Core tools
> Build `tracker.html`: users add stays (country/state via datalist, arrival, departure, note); store in localStorage only; de-duplicate overlapping days per country; settings for counting method (any part of day vs exclude departure day) and window (calendar year or rolling 365 days ending an "as of" date). Show KPI cards (days logged, countries, Schengen days used in the rolling 180-day window, US weighted Substantial Presence days), a per-country table with progress bars against each country's threshold, a trip list with delete, CSV export/import, print report and a sample-data button.
> Build `calculators.html` with tabs: (1) US Substantial Presence Test (current + ⅓ prior + ⅙ second prior ≥183 and ≥31 current-year days, minus exempt days, with days-remaining); (2) Schengen 90/180 (multiple stays, check date, days used, days left, maximum continuous stay and latest exit); (3) UK Statutory Residence Test quick check (automatic overseas tests 16/46/91-day, automatic 183-day test, sufficient-ties table for leavers vs arrivers); (4) India residential status (182 days, 60/365 rule, 120-day rule for citizens with Indian income over ₹15 lakh, deemed residency, ROR vs RNOR); (5) days-left planner for any threshold. Every result states the rule that produced it.
